## 栏目模块insert方法中部分内容讲解
### 源代码
```java
@Override
    public void insert(Category category) {
        //判断 category==null【可不写，前端会处理】
        if (category == null)
            throw new
                    ServiceException(ResultCode.PARAM_IS_BLANK);
        //1.判断 栏目名是否唯一
        LambdaQueryWrapper<Category> qw = new
                LambdaQueryWrapper<>();
        qw.eq(Category::getName, category.getName());
        Category c = categoryDao.selectOne(qw);
        if (c != null)
            throw new
                    ServiceException(ResultCode.CATEGORYNAME_HAS_EXISTED);
        //2.如果包含父栏目，则判断parentId是否有效(存在且为1级栏目)
        Integer parentId = category.getParentId();
        if (parentId != null) {
            Category pCate = categoryDao.selectById(parentId);
            if(pCate == null || pCate.getParentId() != null)
                throw new
                        ServiceException(ResultCode.PARAM_IS_INVALID);
        }
        //3.获取max(order_num)
        // 栏目表中无数据，新插入栏目序号为1
        int order_num = 1;
        // 栏目表中有数据，新插入栏目序号 = max(order_num) + 1;
        if (categoryDao.selectCount(null) != 0) {
            //借助自定义sql语句实现，【简单，推荐】
            Integer mo = categoryDao.getMaxOrderNum();
            log.info("max_order_num: ", mo);
            order_num = mo + 1;
        }
        //4.设置order_num值
        category.setOrderNum(order_num);
        //5.插入
        categoryDao.insert(category);
    }
```

### 判断栏目名是否为一(与已存在栏目名重名)
```java
LambdaQueryWrapper<Category> qw = new
                LambdaQueryWrapper<>();
        qw.eq(Category::getName, category.getName());
        Category c = categoryDao.selectOne(qw);
        if (c != null)
            throw new
                    ServiceException(ResultCode.CATEGORYNAME_HAS_EXISTED);
```
1. **`LambdaQueryWrapper<Category> qw = new LambdaQueryWrapper<>();`**
    - 创建了一个 `LambdaQueryWrapper` 对象，用于构建查询条件。
    - `LambdaQueryWrapper` 是 MyBatis-Plus 提供的一个工具类，支持通过 Lambda 表达式来构造 SQL 查询条件，避免手写字符串字段名，提高代码可读性和安全性。

2. **`qw.eq(Category::getName, category.getName());`**
    - 使用 `eq` 方法添加一个等于条件（`=`）到查询条件中。
    - `Category::getName` 是 Java 的方法引用，表示查询条件基于 `Category` 实体类中的 `name` 字段。
    - `category.getName()` 是传入的栏目名称，作为查询条件的值。
    - 这一行的作用是：查询数据库中是否存在 `name` 字段等于 `category.getName()` 的记录。

3. **`Category c = categoryDao.selectOne(qw);`**
    - 调用 `categoryDao.selectOne(qw)` 方法执行查询。
    - `selectOne` 方法会根据查询条件返回一条记录（如果有多个符合条件的记录，则会抛出异常）。
    - 返回的结果存储在变量 `c` 中。如果查询结果为空，则 `c` 为 `null`；否则，`c` 是查询到的 `Category` 对象。

4. **`if (c != null) throw new ServiceException(ResultCode.CATEGORYNAME_HAS_EXISTED);`**
    - 判断查询结果是否不为空。
    - 如果 `c` 不为空，说明数据库中已经存在同名的栏目，此时抛出一个自定义的服务异常 `ServiceException`。
    - 异常中携带了错误码 `ResultCode.CATEGORYNAME_HAS_EXISTED`，用于标识具体的错误信息（例如 "栏目名已存在"）。
### 如果包含父栏目，则判断parentId是否有效(存在且为1级栏目)

### 获取max(order_num)
```java
//3.获取max(order_num)
        // 栏目表中无数据，新插入栏目序号为1
        int order_num = 1;
        // 栏目表中有数据，新插入栏目序号 = max(order_num) + 1;
        if (categoryDao.selectCount(null) != 0) {
            //借助自定义sql语句实现，【简单，推荐】
            Integer mo = categoryDao.getMaxOrderNum();
            log.info("max_order_num: ", mo);
            order_num = mo + 1;
        }
        //4.设置order_num值
        category.setOrderNum(order_num);
        //5.插入
        categoryDao.insert(category);
```
1. **`int order_num = 1;`**
    - 初始化 `order_num` 为 1，表示新插入的栏目的序号。
2. **`if (categoryDao.selectCount(null) != 0) {`**
    - 判断栏目表中是否有数据。
    - `categoryDao.selectCount(null)` 会返回栏目表中的记录数。
    - 如果记录数不为 0，说明栏目表中有数据，需要获取最大的 `order_num`。
3. **`Integer mo = categoryDao.getMaxOrderNum();`**
    - 调用 `categoryDao.getMaxOrderNum()` 方法获取栏目表中最大的 `order_num`。
    - `getMaxOrderNum()` 方法是自定义的 SQL 查询方法，用于查询栏目表中的最大 `order_num`。
    - 返回的结果存储在变量 `mo` 中。
4. **`order_num = mo + 1;`**
    - 计算新插入栏目的 `order_num` 值。
    - 新插入栏目的 `order_num` 为栏目表中最大 `order_num` 的值加 1。
5. **`category.setOrderNum(order_num);`**
    - 设置栏目对象 `category` 的 `order_num` 字段值为计算得到的 `order_num`。
    - 保证新插入的栏目的 `order_num` 是正确的。
6. **`categoryDao.insert(category);`**
    - 调用 `categoryDao.insert(category)` 方法插入栏目数据。
    - 将栏目对象 `category` 插入到数据库中。
